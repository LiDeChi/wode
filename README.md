# 数字世界 · 窃符

以前这里只有《数字世界设计总稿 v3》。现在可以打开一个本机战国剧场：以新门客身份递话、陪如姬取符，最后看到史书所载或属于本作的结尾；交接与心思会保存，后来还能从另一个人的视角重看。

本项目实现设计稿 §§12、16、24 的第一版：一个人的一个世界、一个历史事件、三部游戏与两种电影呈现、片场和最小导师。游历、多世界、完整研究平台不在此版。真实试玩与考据审定另列，不把自动检查当成人的体验验收。

## 启动

Node.js 22.13+（验证环境为 26.2），npm。服务绑定本机回环地址，默认端口 4318。

```bash
npm ci
npm run dev
```

打开 <http://127.0.0.1:4318/>。生产方式：

```bash
npm run build
npm start
```

SQLite 保存在 `.runtime/worlds.sqlite`；浏览器 HttpOnly 会话 cookie 指向个人世界。不要删除数据目录或清理 cookie 来期待保留进度。需要迁移时，在「导师的笔记」导出 JSON，再在另一浏览器导入。重置前界面要求明确选择，旧演出只留在已导出的文件里。

| 路径 | 一个能复验的小例子 |
| --- | --- |
| 进入这段历史 | 看开场、写入三个偏好、递赵使竹简、劝公子折返；信任记录决定献计是否成立。 |
| 取符之夜 | 方向键/WASD、点地面或屏幕方向按钮移动；Shift/放轻脚步减速。避开守卫视线，取符后返回左侧门外。暂停、离开再进入，脚步记录重算到原处。 |
| 围城 | 先听李同、决定是否请平原君散财，再递印信/借条/担保物。每次从实际仓粮扣两袋。 |
| 点人物 → 看心思 | 相同缺额，多疑者把疑问留到整体核印，急躁者先追人。三层读数来自实际状态；展开可查数字与出处。 |
| 围城 → 同一件事，换个人 | 换守仓人，对照五个固定输入；差别不止台词，层读数、动作和交接流程也不同。 |
| 五次交接 → 片场 → 试作核验办法 | 由网关提出有限 JSON，静态核验后运行同样五次轨迹，通过才安装。超时可明确选择录制办法；来源分别标示。下次会生成双方共享的副页，回滚恢复旧流程。 |
| 片场 → 把交接的原记录摆上桌 | 核验首页与副页，提出旧欠粮记录修订，再经批准。人物志保留“曾经的共识”和受影响的下游。 |
| 作品墙 → 你的后来 | 只用当时事件、心思和凭证剪成电影；不调用模型重新编造结局。 |
| 导师的笔记 | 改细演/普通/一笔带过，查看真实决定、模型使用、失败尝试、token、延迟和费用状态；可导出/导入。 |

## 模型与成本

一个服务器网关，兼容 LiteLLM 的 `/chat/completions`。默认使用 `commandcode/deepseek/deepseek-v4.1-flash`，三个能力槽可单独换模型。没有网关时整个剧情、动作、心智、反转、录制机制都能用有限规则运行；现场对白与现场机制生成不伪装为已接通。

```bash
# 使用自己的环境变量；凭据只在服务器
MODEL_GATEWAY_URL=http://127.0.0.1:4000/v1 MODEL_GATEWAY_KEY=... npm run dev
# 或写入被忽略的 .env，再用 Node 加载
node --env-file=.env --import tsx server/index.ts
```

`.env.example` 仅是选项说明，程序不会自动读取它。模型选择、12 秒对白/30 秒改造等待上限可通过环境变量修改。开发机如果配置 `ANTHROPIC_BASE_URL` / `ANTHROPIC_AUTH_TOKEN`，会自动使用其兼容入口。不要将这些值提交或放入浏览器。

每小时对白 30 次、设想 6 次、改造 1 次；实际发出的失败尝试也计数。额度耗尽后规则接续，新一小时恢复。设想槽为保留能力，首版没有任意生成作品入口。缓存以会话、模型、视图与结构化输入为键。输入、原输出、采用结果与用量保存在 SQLite，可随世界导出。

`MODEL_INPUT_PRICE`、`MODEL_OUTPUT_PRICE` 为每百万 token 的网关计价；未配置时显示“未配置单价”，记录中的 0 不代表免费。超时没有拿到 token 的尝试显示“待对账”。不要以协调步骤下降推断云端费用下降。

## 验证与证据

```bash
npm test
npm run build
npx playwright install --no-shell chromium
# 启动服务后
npm run test:browser
# 完整项目检查（要求服务正在运行）
```

## 当前边界

潜行三分钟上限，失败也写入世界；客户端移动记录由服务器相同固定步长重算。仍属本机个人产品，没有多人共享或对抗作弊平台。

史书层与 `work.*` 本作层分开。《史记》驻军作邺，《战国策》作荡阴，两种短引都保留。十万魏军归养后选八万；侯嬴在公子到军之日送别。服饰、建筑、器物的考古外观尚未人审；主作品约十分钟是节奏目标，需真人测时。角色声音目前是音乐/提示音与声线设计记录，没有人物语音合成。

WebGL2 可用时显示立体戏台；缺少 WebGL 时保留人物与文本入口，不能等同完整立体潜行体验。手机宽度检查使用 Chromium 模拟，真实 iOS Safari / Android 与真人体验需另验。
