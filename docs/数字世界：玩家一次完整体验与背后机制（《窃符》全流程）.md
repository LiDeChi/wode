# 数字世界：玩家一次完整体验与背后机制（《窃符》全流程）

Oct 11, 2026 · @Someone

## 总览

一次《窃符》体验约 10 分钟：对玩家是一部电影加四幕互动，对系统是同一张主张图在不同阶段被读取和写入。下表把每个阶段的体验和机制放在一起，后文逐段展开。玩家看不到右列，除非点开心智入口或进入片场。

| 阶段 | 玩家看到和做的 | 背后的机制 |
| --- | --- | --- |
| 准备 | 无 | 史料转成内核数据，人审定，进入约束层 |
| 第一面 | 《长平之后》电影，导演递来按钮 | 零交互等于录制重放；导师冷启动；导演授予第一个交互 |
| 安排 | 无感知 | 导师定档位，导演定交互档位、预先比例，谁用深层心智 |
| 第一幕 大梁 | 递话，长按看魏王和信陵君的心思 | 角色可得视图、语言通道、心智入口 |
| 第二幕 夷门 | 说话，看侯嬴试探信陵君 | 认可度更新，成因链环节 3 |
| 第三幕 取符之夜 | 护送、望风、短潜行 | 快慢两层，越权要付代价，被发现等于断链 |
| 第四幕 邺城 | 一句话或一个动作 | 动词门、冲突检查，反转事件，两种结局 |
| 收尾 | 拉远，看「史」与亲历版本对照 | 主张图的投影，「本作的历史」 |
| 之后 | 下次开场放你做过的事 | 录制、导师笔记、预测对照、固化为预先 |
| 再来 | 《围城》、换人、其他导演的作品 | 并行、承接，同一张主张图 |

## 开始之前：世界从哪里来

玩家进来之前，世界只是约束，不是已经演出来的事实；作品交付之后，里面的主张才成为事实。

《窃符》的约束分三步准备：

1. 搜集史料。要用原史料核对（《史记·魏公子列传》《平原君虞卿列传》《白起王翦列传》《战国策》），目前引用的是二手文章。
2. LLM 把史料翻译成内核的数据：约 10 个关键角色（信陵君、侯嬴、如姬、朱亥、晋鄙、魏王等）、地点（大梁、夷门、邺、邯郸）、关系、资源，以及六个环节的成因链，每个环节带置信度。
3. 人审定后进入约束层。角色性情是设计假设，不能当史实；「新来的门客」这个玩家身份是虚构的，嵌入真实事件。

成因链里，环节 1（魏王止步）和环节 6（解围）结构牢，玩家改不了；环节 2 到 5 玩家可以影响。

这些数据落在五层架构里：世界内核（实体、关系、资源、时钟和主张图）、行动词表、心智层、约束层、呈现层。呈现层只能读内核，要产生后果必须通过动词。

## 第一面：《长平之后》

玩家第一次看到的是约 1 分钟的零交互电影：长平之战后秦军围邯郸，城中缺粮，赵使求救，魏王令晋鄙止步。电影中途，导演递给你一个按钮，按下去就进入《窃符》。

背后的机制：

- 零交互的电影就是一次录制的回放，几乎不耗算力，可以分享，也是宣传片。
- 这是第一个呈现，玩家还没有自己的世界，所以内容对所有人一样。
- 导师对你还没有了解。它先问两三个很粗的问题（比如能等多久、爱精致还是爱自由），之后靠观察你的选择来修正。
- 按钮是导演授予的第一个交互。授予范围之外没有入口。

## 进入前：导师和导演的安排

玩家按下按钮后、第一幕开始前，导师和导演已经定好这一场怎么演，玩家感觉不到。

- **导师**定档位：细演、普通、一笔带过，以「一场」为单位，用的是真算力。第一版由我们出算力，每位试玩者有固定上限，云端为主。第一版的导师是最小版：三个档位、几个偏好维度、笔记。
- **导演**转三个旋钮：交互档位（0 只看，1 在几个关键点上选，2 去、给、说，3 加自由语言）、预先比例、备好时间。《窃符》定为高预先、局部实时。
- **谁用深层心智**由系统在一场之内判断：在场中心的、与玩家关系近的用深层，其余用浅层。算力用完时深层退到浅层，这一场照样演完。
- **预先的内容带成立条件。** 骨架和关键节拍预先做好；玩家实时改变了局面、条件不成立时，换一段或退回实时。
- **兜底**：准备好录制重放，宣讲时不会因为现场心智出问题而中断。

导演授予的动词决定了玩家每一幕能做什么：第一、二幕是说和看心思，第三幕是动作，第四幕是说或选择。授予范围之外没有入口。

## 第一幕·大梁（1:00–3:00）

你是信陵君府里新来的门客，看着信陵君数次劝魏王无果。你可以递话，也可以长按某个人，看魏王的畏惧和信陵君的焦虑。

背后的机制：

- **角色可得视图。** 每个角色只知道战国那个设定里能知道的，防止时代错置和信息泄露。
- **语言是世界里的话，不是命令。** 你说的话和外来内容先转成带来源的主张，再进入图，不当命令执行，防注入。听的角色用自己的心智去理解，信不信取决于他对你的认可度；你是新来的，起始认可度低。
- **心智入口。** 长按看到的心思，来自角色真实的心智状态，不是临场编的。
- **成因链环节 1 和 2。** 魏王畏秦止步，结构牢，玩家改不了；信陵君穷尽正路，玩家的「说」可以影响。
- **粗粒度。** 每次决定只有 2 到 4 个选项，每个选项的后果明显不同，细节交给心智和系统。

## 第二幕·夷门（3:00–5:00）

信陵君准备率宾客赴秦军死战，经过夷门时，看门人侯嬴不送行。你看出这是一场试探，并可以在场说话。

背后的机制：

- **成因链环节 3。** 侯嬴先试探信陵君，之后献出窃符之计。你在场说的话，会影响侯嬴对信陵君的判断。
- **主张与认可度。** 侯嬴对信陵君的判断是一条主张，带持有者、来源渠道、证据和认可度。你的话是新证据，改变的是侯嬴这条主张的认可度，不能直接改写别的角色已有的主张。
- **你看出的试探来自心智入口。** 你能点开侯嬴，看到他此刻在想什么，也能看到自己的角色此刻想要什么，以及你的选择和角色倾向差多远。
- **冲突检查。** 你的话如果与已被认可的主张冲突，系统算出推翻成本：小的成为「误会」，两个版本并存；大的需要批准，成为反转事件。

## 第三幕·取符之夜（5:00–7:00）

如姬窃取魏王所持的半块兵符，你负责护送和望风。这是一段约 2 到 3 分钟的短潜行，也是整个作品里唯一的动作段。被发现的代价是断链。

背后的机制：

- **快慢两层。** 快层是手感、物理和帧率，用传统引擎，LLM 不逐帧运行；慢层是心智、主张图和叙事，由 LLM 驱动。两层靠「结果变成主张」相连：你被谁看见、击退了谁，之后才会被别人提起。
- **交互由情感决定。** 这是最紧张的一刻，所以导演授予的是动作；同一件事换成别的情感，授予的交互就不同。
- **成因链环节 4。** 如姬一直想报答信陵君曾为她报父仇的恩，兵符在魏王卧室。玩家的动作可以影响这一环。
- **越权要付代价。** 窃符是对王命的欺骗和违抗，是「授予范围之外的动作要付代价」的最高形式。代价小的成为误会，大的成为反转事件。
- **断链。** 在不可替代的环节上被发现，链断开，邯郸可能陷落。作品里把这一路标为「本作的历史」，与史书所载分开，也不回写到史料层。

## 第四幕·邺城（7:00–9:00）

晋鄙合符而疑，朱亥在信陵君身后。这一刻你的一句话或一个动作，改变晋鄙的下场，或信陵君的犹豫。

背后的机制：

- **大转向落在你认识的人身上。** 晋鄙和信陵君，你在前几幕已经看过他们的心智。结构要高度可信，改变才动情。
- **历史能不能被改，要同时满足三个条件。** 你的动作让链上某个人的心智真的变了；这个环节不可替代；这条链的置信度足够高。条件不满足时，历史会自己找别的路径补上，结果相近，细节不同。
- **成因链环节 5 和 6。** 邺城夺军玩家可以影响；解围结构牢，玩家改不了。
- **动词门和冲突检查。** 你的话或动作先经过前提检查，再写成主张。推翻已被认可的主张，要给出新证据、解释旧共识为什么会错、处理下游依赖；代价大的由导演或导师批准，成为反转事件，旧共识标为「曾经的共识」，不删除。
- **预先段落的成立条件。** 前面几幕造成的局面如果使预先做好的这一段不成立，就换一段或退回实时。
- **两种结局。** 史实结局和反事实结局，两种都可达。

## 收尾：拉远与「史」（9:00–10:00）

邯郸解围，镜头拉远。你先看到史书怎么写，再看到你亲历的是什么，最后是侯嬴自刎，以及你认识的人的结局。这一段几乎没有交互。

背后的机制：

- **拉远。** 同一个心智入口可以缩放：人、一屋、一城、一国。只在几个时刻拉远，比如某条主张被引用到一定次数。你做完的事，能看到它在图里长出枝。
- **「史」是主张图的一个投影。** 它是大家共同相信的版本，也就是认可度最高的那一组主张，可以和你亲历的那一版对照。
- **「本作的历史」与史书所载分开。** 被改变的部分标注出来，不回写到史料层。
- **往上走。** 你做的事被越来越多的人认可、引用，权限才扩大。这是太阁立志传式的「从低处往上」，不是数值升级，而是别人怎么看你。

## 体验之后：系统在后台做什么

玩家离开后，这一场留下的东西有五样，下次进来时都会起作用。

1. **写回主张图。** 你的话和动作已经作为主张进入图，被引用越多，认可度越高，推翻成本越高。已交付的主张永久保存。
2. **录制。** 这一场的轨迹和每次 LLM 调用的输入输出都被录制，可以离线重放，也是电影的来源。
3. **导演对照预测。** 导演在设计记录里写下对你的预测，现在与你的真实反应（停顿、卡住、重玩、追问）对照，产生预测误差，用来调整他对你的模型和自己的手艺。第一版只做设想玩家、记录预测、与真实反应对照，不做自动调参。
4. **导师更新笔记。** 它从你的选择（先玩粗的还是等精品，哪些玩到一半就走，哪些反复重玩）和反应里了解你。笔记显示给你，你看得见，也改得了。
5. **固化为预先。** 实时演得好的段落，录下来固化为预先，这是经验沉淀，也是模型调用越用越少的路径。

之后的呈现由导演排片，排片表只分三格：现在、稍后、之后。粗的先玩，精致的在后台备着。

## 再来一次：同一件事，换个视角

第二次进来，玩家最先看到的是自己上次做过的事被拍成了一部电影，而且换了一个人的视角。这是整个体验的核心：玩家第一次明白，差异不是台词不同，而是人不同。

玩家可以走的四条路：

- **看另一面。** 《围城》是邯郸城内的视角：缺粮，平原君散财。同一个事件，由不同的人持有不同的说法，每处差异都能追溯到持有者的信念和渠道。这就是呈现之间的「并行」关系。
- **换人。** 两个不同的守仓人面对同一个缺额：一个多疑，先把所有印信摊开对照；一个耐性低，直接去追借粮者。信息停在心智的不同层，做的事不同，但都说得通。
- **承接。** 上一次产生的新主张，被下一个呈现读到并接着往下；你的选择在第二个呈现里以后果出现。
- **看其他导演的作品。** 同一个事件由不同导演做出不同的作品，作品墙上标明导演。

《取符之夜》也可以独立玩，约 2 到 3 分钟，结果仍写回同一张主张图。呈现之间只有两件事：读取视角范围内的主张，以及通过动作产生新主张；任何呈现都不能直接改写别的呈现里已有的主张。

## 底层持续运作：玩家看不到的三件事

**一、一致性靠四道保证。**

- 单一来源：呈现只读主张图。
- 动词门：改变世界只能通过动词，每次先过前提检查。
- 冲突检查：新主张与已有主张冲突时算推翻成本。先覆盖数量、身份、时间、印信四类，用规则实现。
- 接地检查：叙述里的人物、地点、物品必须引用内核里存在的实体，引用不到的句子不放行。LLM 不直接写主张图。

**二、LLM 是低频的改造者，让底层逐渐自主。** 同类误差反复出现，或导师发起时，走一条改造链：

1. 改造请求只含角色轨迹的结构化记录，不含玩家原文。
2. LLM 生成模块和声明。
3. 静态检查：无网络、无文件、只读声明的字段。
4. 隔离试作，在录制的轨迹上与旧机制对照；重复协调成本至少降 20%，且无越界、无失败才通过。
5. 带版本安装，可回滚。
6. 角色下次遇到同类情形调用它，断网也能运行。

第一版只承诺一条这样完整的链。

**三、调用有预算，超了就降级。** 每个玩家每小时，对话与导演不超过 30 次，设想不超过 6 次，改造不超过 1 次；超出后降级为模板和规则。这些数字只是起点，还没有实测。

玩家离开后，世界不会独立流逝。他回来时系统按规则补算，想看世界现状，也要经过一个呈现。

## 第一版里，哪些是真实运行，哪些是预先做好

第一版是演示，不开放游历；上面的机制并不都以完整形态运行。对外讲的时候，要按下表区分，不声称做不到的事。

| 部分 | 第一版的做法 | 性质 |
| --- | --- | --- |
| 《长平之后》 | 约 1 分钟零交互电影 | 预先制作，录制重放 |
| 《窃符》 | 约 10 分钟，骨架和关键节拍预先做好，只有几个角色的心智现场运转 | 高预先、局部实时，有录制重放兜底 |
| 演员 | 约 10 个关键角色，心智、角色可得视图、心智入口、去给说 | 完整运行 |
| 主张图 | 主张图、冲突检查、反转事件；成因链先做邯郸之战这一件事 | 真实运行 |
| 导演 | 一位完整导演（有设想玩家、记录预测、对照的回路）；其余导演可以是空壳 | 完整的只有一位，其余是设计示范 |
| 导师 | 三个档位、几个偏好维度、笔记 | 最小版 |
| 改造链 | 只承诺一条完整的链 | 真实运行，只有一条 |
| 画面 | 风格化 2.5D，three.js 程序化为主，手工打磨 | 生成模型只做辅助 |
| 片场 | 种子由我们手工做，内容来自真实记录 | 手工做的种子 |
| 科研 | 只做换人测试和一致性检查 | 部分 |
| 游历与共享 | 不做，存储上先把性情手艺与经历分开 | 不对外提 |

## 尚未解决

走完这一遍，有七处在设计稿里没有交代清楚，需要补：

- [ ] **反转事件谁批准。** 设计稿规定代价大的推翻由导演或导师批准，但第一版的导演只有「下一场排给谁」一个动词，导师是最小版，世界记账员又不设。第一版是预先写好，还是现场判定，没写。
- [ ] **「邯郸陷落」算不算在改变幅度内。** 取符之夜被发现可能导致邯郸陷落，但已定的幅度只包括谁来救、何时到、代价、谁被记住。
- [ ] **各幕的语言授予程度。** 语言可以是看不见、选一句、自由说三种程度，第一、二、四幕各用哪一种，没写。
- [ ] **导师第一次问哪两三个粗问题。** 已定要问，但具体问什么没定。
- [ ] **空壳导演怎么呈现差异。** 至少要有一句性情设定和一部按这个性情做的作品；预测与真实反应的对照只属于完整导演，片场里要标明其余是示范。
- [ ] **史料。** 晋鄙止步在邺还是荡阴，围城起止年份，缺粮细节，都要用原史料核对；目前来源是二手文章。
- [ ] **算力上限与调用预算。** 每位试玩者分多少，每小时 30、6、1 次的预算，都没有实测。
