# 战国漆木剧场视觉与资产规范

版本 1，2026-10-11。

世界采用程序化 2.5D，正交镜头，地面在 x/z 平面；人物、建筑、器物由同一 Three.js 工厂构成。竖屏保持人物、可交互物和下一步同时可見。字体有系统回退，网络字体不是进入游戏的前提。

## 材料与时代

画面材料为夯土、漆木、织物、青铜、麻袋、竹简。冷靛背景，暖木墙面，淡金灯光，衣袍由角色包定义。面部、衣领、腰带和帽形保持角色识别。宫廷与粮仓不出现现代用品；片场属于导演的工作区，可出现电影装置。

原文证实铁椎、兵符、粮食和书面记录，未证实本作器物的精确形制、衣服剪裁、建筑复原。造型是原创风格化设计，待考据者人工审定。史料异文见 history-sources.md。

## 一致性

所有作品均引用 `Entity.appearance.assetId` 与 `buildCharacter` 工厂。同一人换场不另造面孔。性情、手艺存在实体，经历存在独立列表。声音习惯是角色包字段；本版文字对白配原创乐音，尚未把声音习惯合成为独立角色语音。

## 原创音频

Web Audio 在用户点击开启声音后播放，五声音阶的规则作曲与事件音效由 `src/presentation/audio.ts` 生成，不调用外部音频生成服务。暂停、静音、隐藏页面、离开场景必须停用或恢复同一条声轨，不能叠加来源。

## 资产索引

资产身份与许可由 `public/assets-manifest.json` 记录。程序化工厂作为来源；无需调用第三方图像/3D生成服务。人物包可复用，纹理缓存和几何共享由 AssetKit 管理；卸载场景释放资源。
