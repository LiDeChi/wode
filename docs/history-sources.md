## 时间核对：先后可用，精确月数尚不能用

已读原典的时间记录如下。史书各篇并非完全一致，不能把它们强行拼成一条无异文时间轴。

| 来源与位置 | 原文短引 | 能确认到哪一步 |
| --- | --- | --- |
| S73，“四十八年十月”后围城段 | “其九月，秦復發兵，使五大夫王陵攻趙邯鄲。” | 记王陵复攻及相对纪年；公元前起点仍需校历。 |
| S73，紧接王陵段 | “四十九年正月，陵攻邯鄲，少利，秦益發兵佐陵。” | 王陵阶段不利，增援。 |
| S73，王龁代将段 | “秦王使王龁代陵將，八九月圍邯鄲，不能拔。” | 有“八九月”这一表述；现代标点不等于已证明其是历月或持续时长，不能据此计算全围城十七个月。 |
| S73，白起死段 | “武安君之死也，以秦昭王五十年十一月。” | 该篇白起死的纪年；不能以此自动认定同日解围。 |
| S05，昭襄王四十八年附近 | “其十月，五大夫陵攻趙邯鄲。” | 与 S73 的“其九月”有差异；跨年、年首、月次需另校。 |
| S05，五十年条 | “十二月，益發卒軍汾城旁。武安君白起有罪，死。龁攻邯鄲，不拔，去，還奔汾軍。” | 白起死附近记王龁退军；与 S73 十一月记死不同，仍不提供完整围城起止日。 |
| S77，救赵段开头 | “魏安釐王二十年，秦昭王已破趙長平軍，又進兵圍邯鄲。” | 魏公子列传按魏王二十年叙救赵；不是长平与围城必定同月发生。 |
| S43，孝成王条 | “八年，平原君如楚請救。還，楚來救，及魏公子無忌亦來救，秦圍邯鄲乃解。” | 赵世家将解围记在八年。 |
| S15，周赧王五十八年行 | 魏二十列：“公子無忌救邯鄲，秦兵解去。”；赵九列：“秦圍我邯鄲，楚、魏救我。” | 年表把救赵与秦五十、魏二十、赵九并列，赵九与 S43 的八年存在篇间差异。 |

S15 网页把长平所在行标为前260年，把救赵所在行标为前257年；这些公元前标签是现代编者的换算，不是《史记》原句。需要绝对年代时可以说明“按该转录表的现代纪年标注，救赵约前257年”，但不得把这一标签当成原文已经独立证明起止年份。

设计稿的“约前258至前257年、围城约十七个月”目前列为待校历结论。已访问的正文没有直接写“十七个月”。首版开场可以用“长平之战后，秦军围攻邯郸；城中危急，赵向魏、楚求援”，既交代进程，也不必等精确月数才能成立。主线现场字幕用“大梁”“夷门”“邺——按《史记》主线”“邯郸”，史料入口保留异文。

## 推断、异说与本作设计分层

| 层 | 具体例子 | 入世界时应怎样标 |
| --- | --- | --- |
| 原典正文已找到 | S77 的十万、八万、邺、如姬盗符、朱亥铁椎、侯嬴自刎；S76 的李同散财劝说 | 带来源编号、原文位置、叙述者／发言人；人物说法保留渠道。 |
| 原典正文间的差异 | S77“邺”与 Z3“荡阴”；S43 赵八年解围与 S15 赵九年条；S73 与 S05 的月次 | 两条来源各自留存；首版采用哪条须明示依据，另一条不能静默删除。 |
| 基于正文的解释 | 晋鄙重视军权责任；如姬可能担心窃符被发现；平原君起初仍保有奢侈生活 | 标为“本作根据史料推断”；具体心理、置信度和性情参数由人审定。 |
| 人物自己的战略判断 | S73 白起说“秦卒死者過半，國內空”，推论邯郸不易攻；侯嬴预测如姬会答应 | 标发言人及其视野。可以驱动角色，不能升为全知叙述中已证明的精确统计。 |
| 物件机制的推断 | “虎符”“合符”支持以兵符验证权力；将其画成两半可以解释合符 | 半块的具体材质、虎形比例、铭文、尺寸在本次引文中未核；不能将设计稿“半块”当作 S77 的逐字记载。 |
| 明确虚构 | 玩家新门客、取符夜的护送望风、守仓人与借粮者、印信／借条／担保物的交接、具体地图路径与警戒值 | 标为“本作设计”，引用设计稿和场景版本，不能伪造史料链接。 |
| 反事实 | 晋鄙生还、如姬被发现、不同救援时机、邯郸在本作失守 | 标为“本作的历史”，记录由哪次选择和哪条模型成因链造成；史料原记录保持不变。 |

“取符失败，所以邯郸必陷落”不能作为已核实的历史因果。S76 还有李同的城内行动与楚援；本作若让取符失败导致失守，须承认这是局部反事实模型的结局，而非真实历史必然性。§16.3 的“解围结构牢”与同节“断链可能陷落”也需在结局说明中落实条件，不能同时无条件成立。

## 首版取用约定与待人工审定

- 场景主线采用 S77：大梁／夷门 → 如姬窃符 → 邺城合符、夺军 → 选兵八万 → 救赵。采用这一主线不表示已经消除 Z3 的荡阴异文。
- 《围城》采用 S76 的背景与李同、平原君这一条线；原创粮仓交接用来演示心智与主张，并明确与史料人物区分。
- 结尾“史书所载”显示杀晋鄙、解围、侯嬴按约到军之日自刎；电影剪辑顺序可以不同于事件时间，回顾时要交代先后。
- 精确公元前起止月、十七个月、古代斤／里的现代换算、虎符形制、服饰、建筑、声音、算具均未完成考据。尤其不能因为体验稿举了“算盘”便宣称战国器物已获验证。
- 人工审定应保存审定者、日期、采用的源版本、结论与仍有争议处；本次阅读不冒充独立史学审稿或视觉考古验收。

可复查小例子：点 S77，搜索“父子俱在軍中”，随后读到“得選兵八萬人”；再向前搜索“十萬眾”。这能验证“归养筛选改变兵力”的时序，却不能验证游戏里某一名虚构士卒的家属资料。
