# 第二階段：基於同一個世界設定，多個呈現之間的關聯

打開 `node server/index.mjs` 後訪問 http://127.0.0.1:4320/world.html（第一階段頁頂也有入口）。

## 以前卡在哪
第一階段只證明了「每個決定追得到你」。四部作品（《長平之後》《取符之夜》《竊符》《圍城》）各演各的，`claims.relations()` 寫好了但沒有任何作品真的往主張圖裡讀寫，五種關係從沒被算出來過。

## 現在能做什麼
- `shared/engine/works.js`：每部作品只做兩件事——讀它看得見的主張、用動作（含你的選擇）放回新主張。演完後五種關係由主張圖算出，不是手寫標籤。
- 你在三部作品裡各有一個機關（選擇）；撥一下，世界按同樣規則重長一遍，線跟著變，頁面用一句話告訴你哪對作品的關係從什麼變成了什麼。
- 導演的性情參與世界：爭推翻「邯鄲存糧尚可支撐」這條被沿用過的共識（推翻成本 4.5 ≥ 4）時，愛雕琢的陸導要兩件證據，愛放開的單導一件就批。批與不批寫進賬本（`director.approve / director.refuse`），也進服務審計。
- 被推翻的主張不刪，頁面下方「曾經的共識」留著它和推翻它的解釋。
- 點任何一根線：浮層列出兩邊的主張（持有者、渠道、推翻成本、狀態）和「這根線為什麼在」——一路追回你初見時說的話和你在各作品裡的選擇。

## 可複驗的小例子（同樣回答「可以等 / 雕琢好的一段 / 越細越好」→ 陸導）
| 你在《圍城》選 | 《長平之後》→《圍城》 | 原因 |
|---|---|---|
| 拿著倉簿副頁去報 | 爭議 | 1 件證據，陸導要 2 件，沒批，守倉人的說法掛著推不動 |
| 拉上李同一起去報 | 反轉 | 2 件證據，陸導批了，城外的說法成了曾經的共識 |
| 先瞞下來 | 引用 | 守倉人沿用城外說法 |

再把《取符之夜》改成「搶在巡夜前衝過去」：《竊符》與《圍城》從「爭議、並行」變成「並行、引用」——符沒帶出來，魏軍仍停在鄴，城裡聽到的「魏軍不會來了」和魏營裡的說法一致了。

自動檢查：`npm test`（29 項全過；新增 `tests/stage2-works.test.js` 8 項：五種關係都算得出、每條作品寫入與導演裁決都追得到你、一個動作改變兩部作品的關係、導演性情改變走向、曾經的共識保留、瞞下來無反轉、並行差異追得到渠道、同輸入同世界）。

## 還不支持
- 四部作品的內容還是「劇本化的主張操作」，不是能玩的場景；你在作品裡只能撥一個機關。真正的可玩性是第三階段。
- 觀看順序固定（長平之後 → 取符之夜 → 竊符 → 圍城），還不能自己排序。
- 「這根線為什麼在」偏寬：每部作品開排時以你上一條輸入為根，所以前面作品裡的選擇也會列進後面的鏈。
- 片場只列導演對每拍的鎖/放，還不能進去改。
- 世界頁的選擇存在瀏覽器 localStorage，不寫伺服器存檔。
