## 1. 以前卡在哪（三個卡點）

1. **賬本在，但你看不見它。** 每一條決定都躺在 `shared/core/ledger.js` 的 entries 裡，程式能算、測試能斷言，但用戶打開瀏覽器是空的（`web/` 目錄是空的）。所以「導師決定把預算給這幾場」對用戶來說只是一句宣傳語，沒有可查的痕跡。

```

**第 3 步：你應該看到（我當時的實測值）**

- 導師挑的導演：**陆导**（lu）；定的情緒：**悲悯**；交片時機：**稍后**；預算：**10 / 10**

**第 4 步：點導演決定節點 `#32`，追溯路徑應該是**

```

```

節點 `#22` 是 `user.meet`（你交的三個答案 + 那句需求），`#31` 是 `mentor.brief`（導師把「悲悯」這個口味交給 lu，預算 10），`#32` 是 `director.design`。高亮的三個節點與麵包屑一字不差，這條線就是「導演的決定 → 導師的指派 → 你的原話」。

**第 5 步（可選）：再點一個導演決定 `#37`（邺城那筆 grant）**，路徑會是

```
#22 你 → #31 導師 → #32 導演 → #37 導演

——grant 不是憑空發的，它接在設計藍圖後面，藍圖又接在導師的指派後面，指派接在你的原話後面。

做完「點兩個反應 + 看完」後，審計帶會從 17 變成 `20 個決定 · 20 個追得到你 · 0 個孤兒 · 導師 11/11 · 導演 9/9`；再改一條導師筆記，變成 `21 個決定 · 21 個追得到你 · 0 個孤兒 · 導師 12/12 · 導演 9/9`。**孤兒數一直是 0**——這就是第一階段要證的那句話：每個決定都真的沿 cause 走到了用戶。

## 6. 哪些情況不支持（講清楚，免得你以為壞了）

1. **模型不在線時，角色的「說法」會退回規則台詞。** 這是設計，不是故障：旁注一次送 6 句，單句最多等 6 秒，慢了就直接用規則那句話，並在賬本記一條 `gateway.call`。我實測過兩種：
   - 用 repo 預設的模型名（本機網關 404）：`這一批 6 句：0 句模型說的、6 句退回規則台詞` → 畫面上 0 個「模」、22 個「規」，賬本多 6 條 gateway.call，審計仍 `21/21、0 孤兒`。
   - 用有效的模型名（見第 6 條）：`這一批 6 句：6 句模型說的、0 句退回規則台詞`，6 個「模」徽章。
2. **repo 預設的兩個模型名在本機網關是 404。** `server/index.mjs:15` 的 `group/auto-glm-5-3-flash` 與 `:17` 的 `commandcode/deepseek/deepseek-v4.1-flash` 都打不通，`/api/speak` 直接回 `502 {"error":"primary: gateway 404; fallback: gateway 404"}`（0.067 秒，兩邊都秒掛），但 `/api/health` 仍報 `gateway:true`——因為 health 只檢查網關首頁活著，沒檢查模型名。**這不在我的 in-scope（在 `server/`，不是 `web/`），已回報 captain。** 換成 `MODEL_FAST=group/haiku-5.5 MODEL_FALLBACK=group/auto-claude-opus-5-5` 就正常。
3. **推理模型 + 小 max_tokens 會拿到空字。** 旁注請求只給 `max(64, maxChars*4)=160` token，推理模型會 `finish_reason:length` + `content:null`，於是被判成空、退回規則（或落到 fallback 模型）。我實測「模」徽章那 6 句最後全部由 fallback 模型 `group/auto-claude-opus-5-5` 產出。
4. **模型寫的句子品質不穩。** 同一批裡有生活話（`你肯耐着性子等，我便一刀一刀细细雕，急不得。`），也有文言腔（`君要一段精雕之戏，吾便细细琢磨，务使其工。`）。規則句仍然可讀，所以退回規則不算災難，但模型腔調還沒調。
5. **一次只配 6 句。** 按鈕會說「還有 N 句可以配」，要再按才會配下一批。
6. **刷新之後，導演「猜你」的那份記憶會丟。** `shared/engine/session.js:29` 的 `createSession({saved})` 只還原 `PEOPLE` 的 minds，`directors[id].mind.others.player`（guess / lastPredicted）讀回來是空的。畫面上的 `state.predictions` 還在（那是單獨存的），所以命中率照樣算得出來；受影響的是遊戲畫面那條路。**同樣不在我的 in-scope，已回報 captain。**
7. **這是第一階段。** 只有「看見信息流動 + 追到用戶」這一頁；沒有遊戲演出畫面、沒有聲音、沒有多版本存檔、沒有分支歷史。存檔只有一本（`.runtime/world.json`），按「存檔」就是覆蓋它。
8. **頁面會自動讀回上一本存檔。** 打開就看到上次的世界，不是初見。要回到初見請按「重來」。
