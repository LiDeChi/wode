# 数字世界首版工程证据

核对日期：2026-10-11。画布运行编号：`release-20261011-4`。以前只有设计稿，现在本机可走通《窃符》、粮仓交接、取符潜行、片场与事件电影；本报告记录实际执行结果，不代替真人体验或历史审定。

## 复验入口与范围

启动：`npm ci` → `npm run build` → `npm start`，打开 <http://127.0.0.1:4318/>。实现范围为设计稿 §§12、16、24 的战国第一版。底层为 TypeScript、Three.js、Vite、Node HTTP 与 SQLite，一个人的一个世界；后续游历、多世界、任意生成作品、完整科研与完整导师层不在此版。

| 要验证的事 | 点击路径与可复验例子 |
| --- | --- |
| 主线与不同结局 | 进入这段历史 → 跳过或看完开场 → 写入偏好 → 递赵使竹简 → 劝公子回头 → 实际取符并回门外 → 去邺城；朱亥与重新核验分别导向史实／本作结局。 |
| 库存与凭证 | 围城 → 请他打开家库 → 连续递印信：库存 24→22→20，每个画面粮堆代表两袋；递借条／担保物改变桌上物件。重新打开作品读取保存记录。 |
| 心智与换人 | 点守仓人看三层心智，再点“同一件事，换个人”；同一缺额，两人的误差分配、行动与理由不同。 |
| 改造与反转 | 五次交接 → 片场 → 试作核验办法；来源、审核与五次对照可展开。核验原账册并批准反转，人物志仍保留曾经的共识。 |
| 保存与电影 | 暂停 → 回到作品墙 → 接着演，返回原位置；“你的后来”用已记录事件剪成电影。导师笔记可导出／导入。 |

## 审查与失败修复记录

实施子代理 history-research、world-kernel、theatre-builder 已交付并释放文件；主代理执行构建与测试。独立审查与反驳工作流 `qiefu-release-audit`（18 个代理，7 个确认项）发现以下问题；其中两个粮仓项由同一状态渲染修复覆盖。末轮 `granary-final-check` 独立复核交接渲染与证据边界，进一步发现回放借用当前库存；已改为从原种子与事件序列重建当时状态，并用两段电影恰好相差 168 三角面验证。未带 choice 的合法交接按已生成凭据识别；奇数库存画较小的末堆，容量上限由契约传入。

| 确认项 | 修复与验证位置 |
| --- | --- |
| 粮仓固定六袋、不随库存变化 | GranaryView 从实际 resources 传入环境，交接减少粮堆；浏览器库存与三角面回归检查。 |
| 凭证选择只有文字变化 | 场景按最后记录显示印信／借条／担保物，刷新从事件读取；安装核验方法展示匹配副页标记。 |
